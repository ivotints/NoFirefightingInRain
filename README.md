# No Firefighting in Rain

A RimWorld 1.6 mod that stops colonists from fighting unroofed fires while it's raining, since the rain puts them out anyway. Fires under a roof and manual orders still work as usual.

## Requirements

- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)

## Installation

1. Download or clone this repository.
2. Put the mod folder (containing `About/` and `Assemblies/`) into RimWorld's `Mods/` directory.
3. Enable Harmony, then this mod, in the mod list. Harmony must load first.

## Settings

Open **Options -> Mod Settings -> No Firefighting in Rain** to:

- Turn the behavior on or off.
- Set the rain threshold (0.00-1.00, default 0.50). Colonists skip unroofed fires only when rain intensity is above this value.
